Context Engine website

This folder contains the complete site:
- index.html: the jellyfish landing page
- dashboard.html: the interactive project dashboard
- assets/: the bundled images and background graph artwork
- CSS, JavaScript, and static data files used by both pages

To run locally, open a terminal in this folder and run:
  python3 -m http.server 8000

Then open http://localhost:8000/ in your browser. Use “Open workspace” or
“Get started” on the landing page to enter dashboard.html.
